# Changelog

## 0.2.0 - 2026-11-06

- Virtual USP-style transaction matrix, RAM/ROM memory model.
- Window generation and overlap validation.
- Atomic task claims with lease expiry semantics.
- Minimal 68000 instruction smoke-test interpreter (not Musashi).
- Local ROM hashing and manifest generation.
- Initial local-only MasterVisor API and browser dashboard.
- Repository CI, security policy, contribution workflow and documentation index.

### Known limitations
- No full ISA emulation, TOS/Amiga boot, measured bus timing or physical hardware.
- No authenticated API; localhost development only.
