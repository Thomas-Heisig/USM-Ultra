Was ist hier bedienbar?

Die Online-Ausgabe stellt die Navigation, den Modulstatus und eine kleine BASIC-Demonstration bereit. Die vollständigen Python-API-Funktionen, Speicherabbilder, ROM-Loader und CPU-Debugger laufen weiterhin nur im lokal gestarteten MasterVisor.

Maschinenprofile

USM-6502 SBC: teilweise im lokalen Virtual Lab nutzbar. Apple I, Apple II, PET, VIC-20, C64, Atari 400/800, BBC Micro, Atari 2600 und NES sind geplante Systemprofile, noch keine vollständigen Emulatoren.

Zusammengestelltes System

Adressraum (schematisch)

Adressbereiche sind nur Vorschläge, keine automatisch gültige Verdrahtung. Busbreite, Interrupts, DMA, MMU, Takt und Registerzuordnung müssen für jedes Maschinenprofil separat spezifiziert werden.

Speicher · RAM/ROM

Maschinenspezifische Speicherabbilder, Image-Loader und Snapshots werden im lokalen Virtual Lab verwaltet. Auf GitHub Pages sind sie nicht mit einem Server verbunden.

Keine ROM-Dateien hochladen: Diese öffentliche Ausgabe besitzt keinen privaten Speicherbereich.
